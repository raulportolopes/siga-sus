# SIGA-SUS

Protótipo que lê o PDF do prontuário de internação, conta os procedimentos por dia e monta o espelho da AIH com os códigos SIGTAP (competência 08/2026).

A leitura acontece no navegador, sem IA e sem enviar nem guardar dados do paciente.

Site: https://siga-sus.magox.tech

SIGA-SUS é um protótipo independente e não é um sistema oficial do Ministério da Saúde.
